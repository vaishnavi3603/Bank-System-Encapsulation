 🏦 Bank System (Encapsulation Project)

 📌 Project Description
This is a simple Banking System project developed using Java.  
It demonstrates the concept of Encapsulation in Object-Oriented Programming.

🚀 Features
- Create multiple bank accounts
- Deposit money
- Withdraw money
- Check account balance
- Menu-driven system (user input)
- Data hiding using private variables

🛠️ Technologies Used
- Java (Core Java)
- OOP Concepts (Encapsulation)
- Eclipse IDE
- Git & GitHub
